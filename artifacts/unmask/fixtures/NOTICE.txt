Unmask fixtures

These files are test fixtures for the Unmask model bake-off and the Unmask
engine tests. They are not part of the Ritools application. Each file stays
under the licence named below. The MIT licence of the Ritools repository does
not apply to these files.

The files are local. The bake-off and the tests read them from this folder.
They need no network request. The source pages and the source files are named
for provenance. The SHA-256 value is for the shipped file, not the source.

A derivative that is a resize or a crop is a change under the named licence.
A CC BY-SA derivative stays under the same licence. A CC BY derivative keeps
the attribution. A public domain or CC0 file has no condition.
