# Folio PDF engine notices and provenance

Folio pins `pdfjs-dist@5.4.624` (Apache-2.0) for reading and rendering and
`pdf-lib@1.17.1` (MIT) behind one application-owned writer adapter. The writer
adapter is `src/features/folio/folio.writer.ts`. No other writer is included.

## Served assets

`apps/web/scripts/copy-folio-assets.ts` copies the exact published files to
`apps/web/public/folio/` before development, production, and Worker builds:

- PDF.js `cmaps/`, `standard_fonts/`, and `wasm/` trees, including their
  published license files.
- The PDF.js Apache-2.0 text, the CMaps and standard-font terms, the WASM
  license files, the pdf-lib MIT text, and the licenses of pdf-lib's declared
  runtime dependencies (`@pdf-lib/standard-fonts`, `@pdf-lib/upng`, `pako`,
  `tslib`). The generated `notices/VERSIONS.txt` records the pins.
- `apps/web/public/folio/sample.pdf`, generated by the issue 25 sample script.
  Its content is CC0-1.0; it contains standard Helvetica text, one note, one
  text field, and one checkbox.

The build does not claim a reproducible binary, a complete transitive notice
inventory, registry signatures, or a security audit. The minified and unminified
pdf-lib bundles keep different source comments; the copied license texts and the
issue 25 inventory are the provenance record.

## Runtime cache and network

The service worker caches only the `/folio/` allowlist, the generated sample,
and the hashed Folio and PDF.js Worker scripts. It never caches a user PDF,
password, note, form value, output, or session state. The assets and Workers are
same-origin. The engine sends no request that contains a file name, bytes, form
value, note, or password.

## Fixtures

`src/features/folio/fixtures/manifest.json` records the bytes and SHA-256 of
every synthetic fixture. The generated text and shapes are CC0-1.0. The signed
and encrypted diagnostics are synthetic. `signed.pdf` uses a disposable test
certificate and makes no trust claim. `encrypted.pdf` opens with the synthetic
password `folio-test`. The non-Latin fixture embeds a subset of NotoSansJP from
the `@embedpdf/fonts-jp@1.0.0` package under OFL-1.1. No user PDF or private key
is in the repository.
